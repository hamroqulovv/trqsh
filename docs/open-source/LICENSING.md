# Planned AGPLv3 transition

The current source and published releases are licensed under **Apache-2.0** as stated in the root `LICENSE` and `NOTICE` files. This planning document does not replace those terms.

The project owner has selected **GNU AGPLv3** for a future release. The proposed SPDX identifier is `AGPL-3.0-only`; the exact transition release and any third-party notices will be recorded in the dedicated licensing change.

AGPLv3 permits commercial use. Section 13 requires users who modify a network-interactive covered program to prominently offer its Corresponding Source to users interacting with that version remotely. It does not automatically relicense independent applications merely because they send traffic through a tunnel.

Before that release, the project will:

1. Review copyright ownership, contributions, dependencies and retained third-party license/attribution notices.
2. Update `LICENSE`, `NOTICE`, contribution guidance, package metadata and release artifacts consistently.
3. Define an accessible source offer for modified hosted versions and a way to identify the corresponding source revision and build instructions.
4. Update README badges and the organization profile when the new license actually takes effect.
5. Preserve the rights already granted for earlier Apache-licensed copies and releases.

Brand and trademark guidance will be considered separately from the software license. No additional commercial-use ban is planned.

References: [GNU AGPLv3](https://www.gnu.org/licenses/agpl-3.0.html), [GNU license guidance](https://www.gnu.org/licenses/licenses.html), [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0), and the [Open Source Definition](https://opensource.org/osd).
