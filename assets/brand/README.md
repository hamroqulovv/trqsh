# trqsh logo

`trqsh-logo-source.png` is the original image supplied by the project owner as `White.png`.

`trqsh-logo-rounded.svg` embeds those original PNG bytes and clips only the outer canvas to a rounded square. The mark, color, position and pixel content stay unchanged; no generated replacement mark is used. The corner radius is 12% of the canvas width, and the exterior corner areas are transparent.

The main README uses the stable path `assets/brand/trqsh-logo-rounded.svg`. A future logo can replace that asset without changing README layout. Keep the source image alongside the rendered asset and update the embedded PNG when replacing it; changing the source PNG alone does not update the SVG.

Application, desktop and package icons are not changed in this documentation pass. Logo/brand licensing and a trademark policy are part of the separate open-source release plan.
